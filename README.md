# Проект «Челябинск» · C.L.K — loading screen

CCTV-экран загрузки по лору проекта «Челябинск»: камеры полигона, номер субъекта, лог доставки (реальные колбэки загрузки GMod), подсказки по ролям, карме и Чистилищу.

## GitHub Pages

После пуша в `main`:

- https://eutyuganov-droid.github.io/GAGAGA/
- https://eutyuganov-droid.github.io/GAGAGA/loading.html
